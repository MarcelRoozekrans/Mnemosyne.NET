## Goal

A reader learns what variant selection does and how to switch it on, and a self-checking sample proves it: a new, stronger version gets tried and then overtakes the incumbent.

## Approach

**Sample.** `samples/Mnemosyne.Samples.Variants` is a console app that needs no Docker, no model and no API key (Marcel, 2026-11-07: simulated agent runs). It builds `ReasonletCandidate` lists by hand, with an incumbent version (many runs, rate 0.7) and a new child version (no runs, true rate 0.9), and runs a scripted loop of recalls through `ReasonletSelector` wrapped in `VariantSelector`. Each round draws an outcome at the chosen version's true rate from a fixed-seed generator and updates that version's metrics. It prints three acts: the default ranking, which never picks the new version; grouping only, which returns one variant per lineage; and exploration, where the new version is tried early and ends up chosen most of the time. It checks its own receipts and exits 1 if they differ, through `SampleRunner`. It is added to the solution and to the CI sample steps (no database step).
