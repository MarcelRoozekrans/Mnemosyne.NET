# Data protection guide Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One guide that maps a deployer's GDPR duties to the Mnemosyne features that support them, says what the library does not do, and places the EU AI Act, with links from the pages that already hold the mechanics.

**Architecture:** Documentation only. The guide is a map: it states the duty, names the feature and links the page with the mechanics. New facts appear only where no page has them yet, and each is checked against `src/`.

**Tech Stack:** Docusaurus (`npm run build`), Markdown.

**Spec:** `docs/superpowers/specs/2026-11-06-phase-4.6-data-protection-guide-design.md`

## Global Constraints

- Docs only. A gap found in the product is filed as an issue, not fixed here.
- Front matter is `title` and `sidebar_position: 10`. `onBrokenLinks` and `onBrokenAnchors` throw, so every link and anchor must resolve.
- Never write that Mnemosyne is "GDPR compliant" or "AI Act compliant". Write what supports which duty. Open the page with a not-legal-advice note.
- Confirm each GDPR article number against the regulation text (fetch the EUR-Lex or gdpr-info.eu page) before it is written. Drop a number that cannot be confirmed. Same for the AI Act.
- Run the `anti-slop` skill on every page before its commit. Style: concrete first, limits last.
- Commits: conventional, free scopes, no Claude signature, no nested parentheses in a message body. Work on `docs/phase-4.6-data-protection-guide`; push with an explicit `branch:branch` refspec, because `push.default` is `upstream`.
- Phase 4.5 is built first when its pages are linked; if `overview.md` or `daedalus-and-thalos.md` does not exist yet, skip those two links and note it in the PR.

## Review Focus

- Every row of the duty table links a page that really supports the claim (Task 1).
- The "does not do" section is complete and each gap carries an action, not only a warning (Task 1).
- The AI Act section classifies nothing and names no obligation it cannot source (Task 2).
