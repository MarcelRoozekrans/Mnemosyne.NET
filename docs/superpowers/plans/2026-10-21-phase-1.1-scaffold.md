# Phase 1.1 Repo Scaffold Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An empty but releasable Mnemosyne.NET: three packages that build, test, pack and pass a Native AOT gate in CI, with GitVersion, release-please, Renovate and Codecov wired like Rag.NET.

**Architecture:** Copy Rag.NET's repo files (`~/Projects/Prive/Rag.NET`) and cut them down to three packages. Add one thing Rag.NET lacks: an AOT gate. A console app roots every package assembly with `TrimmerRootAssembly`, so the AOT analysis covers all of their code, and is published with `PublishAot=true`. Any IL warning fails the gate.

**Tech Stack:** .NET 10 SDK (`10.0.100`, `rollForward: latestFeature`), slnx, central package management, xunit v3 on Microsoft.Testing.Platform, GitVersion 6.8.2 as a local tool, release-please v5 on the release bot App token, Codecov over OIDC, NuGet Trusted Publishing.

**Spec:** `docs/superpowers/specs/2026-10-21-phase-1.1-scaffold-design.md`

## Global Constraints

- Target `net10.0`. Nullable on, ImplicitUsings on, `TreatWarningsAsErrors=true`.
- Package IDs: `Mnemosyne.NET.Abstractions`, `Mnemosyne.NET`, `Mnemosyne.NET.PostgreSql`. Each has its own `Description` and `IsAotCompatible=true`.
- Package metadata: Authors `Marcel Roozekrans`, license `MIT`, project and repository URL `https://github.com/MarcelRoozekrans/Mnemosyne.NET`. Symbols are `snupkg`. Each package packs its own `README.md`.
- No package icon. There is no brand mark yet, so leave out Rag.NET's `PackageIcon` item.
- `GitVersion.yml` sets `next-version: 0.1.0`. `release-please-config.json` uses `release-type: simple` and `bump-minor-pre-major: true`.
- Commits are conventional. `.commitlintrc.yml` uses Rag.NET's rules: `bench` is an allowed type, and `subject-case` is off.
- Copy a Rag.NET workaround only when its reason still holds on the pinned SDK. Each one that is kept carries its comment, cut down to the part that applies here.
- On the shared agents VM, run test suites one at a time.

## Review Focus

1. **Fresh clone, fresh `obj/`:** `dotnet test` without a prior build must work, or CI must build first. Rag.NET needed a build step for an SDK regression. Task 1 checks whether this SDK still has it.
2. **An AOT-unsafe call in a package:** the gate must fail. Task 2 proves it with a temporary `Type.GetType(string)` call and reverts it.
3. **A new `src/` project added later without `IsAotCompatible` or `Description`:** the conventions test in Task 1 must catch it.
4. **A new `src/` project added later but missing from the AOT smoke app:** the conventions test in Task 2 must catch it, so the gate can't quietly stop covering a package.
5. **Pack on a branch with no tags:** it must produce `0.1.0-<label>.N` prerelease versions, never the SDK default `1.0.0`. Task 3 asserts this.
