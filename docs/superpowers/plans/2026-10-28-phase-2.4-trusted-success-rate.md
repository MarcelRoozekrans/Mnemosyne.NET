# Phase 2.4 Trust-Weighted Success Rate Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:**
- Ranking weighs agent-only runs at `AgentVerdictWeight` (default 0.5), using new judged counters that the PostgreSQL store maintains.
- Every recall match carries `ReasonletEvidence`.

**Architecture:**
- **Abstractions** gain the judged counts on `ReasonletMetrics`, plus a new `ReasonletEvidence` on `ReasonletMatch`.
- **The selector** weights runs.
- **The PostgreSQL store** adds migration 0003 and keeps the counters in step in every writer. It also gains a `min_binary_schema` gate.

**Tech Stack:**
- .NET 10
- PostgreSQL 17 + pgvector
- ZeroAlloc.ORM 2.10.0
- xunit v3

**Spec:** `docs/superpowers/specs/2026-10-28-phase-2.4-trusted-success-rate-design.md`

## Global Constraints

- **Judged:** a run is judged when `evaluated_success IS NOT NULL OR feedback_worked IS NOT NULL`. A judged success is a judged run whose effective `success` is true.
- **`ReasonletMetrics`:** `ReasonletMetrics(int Runs, int Successes, DateTimeOffset? LastSuccessAt, DateTimeOffset LastExecutedAt, int JudgedRuns = 0, int JudgedSuccesses = 0)`. `Validate()` adds four rules, each failing with its property as the path:
  - `0 <= JudgedRuns <= Runs`
  - `0 <= JudgedSuccesses <= JudgedRuns`
  - `JudgedSuccesses <= Successes`
  - `Successes - JudgedSuccesses <= Runs - JudgedRuns`
- **`ReasonletEvidence`:** `public readonly record struct ReasonletEvidence(int Runs, int JudgedRuns, bool UsesParentPrior)`. `Validate()` requires `0 <= JudgedRuns <= Runs`.
- **`ReasonletMatch`:** `public sealed record ReasonletMatch(ReasonletDefinition Reasonlet, ReasonletScore Score, ReasonletEvidence Evidence)`. `Validate()` validates the evidence with the path prefix `Evidence`.
- **`ReasonletRankingOptions.AgentVerdictWeight`:** a `double` in [0, 1], default 0.5, validated like the other weights. It is not part of the weights-sum rule.
- **Rate**, with `w` the agent verdict weight and `k` the prior weight:
  - `weightedRuns = JudgedRuns + w*(Runs - JudgedRuns)`
  - `weightedSuccesses = JudgedSuccesses + w*(Successes - JudgedSuccesses)`
  - `rate = (weightedSuccesses + k*prior) / (weightedRuns + k)`
  - The parent prior is `max(weighted smoothed parent rate, 0.5)`.
  - `UsesParentPrior` is true exactly when a parent exists and its weighted smoothed rate is above 0.5.
- **Migration `0003_judged_counters.sql`** does all of the following and contains no BEGIN or COMMIT:
  - adds `judged_runs` and `judged_successes`, both `int NOT NULL DEFAULT 0`;
  - backfills them from the stored executions;
  - adds the four CHECKs;
  - upserts `schema_version` = 3 and `min_binary_schema` = 3.
- **Store version gate:**
  - `SchemaVersion` = 3.
  - The gate also fails with `Unavailable` when `min_binary_schema` > `SchemaVersion`. A missing setting counts as 0.
  - The message says the binary is too old for the database.
- **Lock order:** unchanged. Reasonlets, then executions, then metrics.
- **Commits:**
  - conventional, never `fix:`;
  - the Abstractions/selector change is `feat!:`;
  - each ends with a blank line and `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`;
  - no nested parentheses in commit bodies.
- **Coverage:** 100% line and branch, merged across both test projects. Warnings are errors.

## Review Focus

1. **Feedback that only changes the judged state.** Feedback with `Worked` equal to the agent's own verdict, on an agent-only run, adds 1 to `judged_runs`. It adds 1 to `judged_successes` only if the verdict is true, and leaves `successes` unchanged. Task 2.
2. **Erase.** A subject erase that removes judged and agent-only runs subtracts exactly the judged ones. The invariant helpers agree afterwards. Task 2.
3. **Backfill.** It counts feedback-judged runs as judged and leaves pruned history as agent-only. A database upgraded from schema 2 passes all four CHECKs. Task 2.
4. **`w = 1` changes nothing.** For random metrics, the rate at `w = 1` equals the phase 1.6 formula exactly. Task 1.
5. **Old-binary gate.** `min_binary_schema` = 4 against `SchemaVersion` 3 makes every store operation that checks the schema return `Unavailable`. Task 2.
