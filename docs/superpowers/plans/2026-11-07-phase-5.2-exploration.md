# Phase 5.2 Exploration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** With exploration on, a new version with few runs is sometimes chosen over the best known variant, reproducibly when seeded.

**Architecture:** `VariantSelectionOptions` adds the switch, the seed and a minimum number of trials. In Thompson mode `VariantSelector` picks one candidate per lineage by a Beta draw on its smoothed success counts, then lets the inner selector score and order the picks. A hash-seeded generator makes the draws reproducible per query.

**Tech Stack:** .NET 10, xUnit, ZeroAlloc.Results.

**Spec:** `docs/superpowers/specs/2026-11-07-phase-5.2-exploration-design.md`

## Review Focus

- The prior is the one `ReasonletSelector.SuccessRate` computes, including the parent's head start and the agent-verdict weight.
- Seeded mode is stateless: two calls with the same seed, question and data pick the same variants, in any order and concurrently.
- `MinTrials` forces the variant with the fewest runs, ties by id, and stops forcing once every variant has enough runs.
- The `explored` count is the lineages whose pick is not the highest smoothed rate.
- The simulation has a fixed seed and no clock.
