# Phase 5.1 Variant Selection Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A host opts in with `AddMnemosyneVariantSelection()` and recall returns one variant per lineage, the best by the inner ranking.

**Architecture:** `VariantSelector` wraps an `IReasonletSelector`: it ranks every candidate through the inner selector, keeps the first match of each `LineageId`, then applies `Top`. A service extension decorates the registered selector. The recall activity gets two count tags.

**Tech Stack:** .NET 10, xUnit, ZeroAlloc.Results.

**Spec:** `docs/superpowers/specs/2026-11-07-phase-5.1-variant-selection-design.md`

- The repo refuses `dotnet test --filter`: build first, then run the test exe with `-class <FQN>`.
- The selector must not change `ReasonletSelector`, `AddMnemosyne` or any 1.0 member.

## Review Focus

- A lineage whose variants are all below the cut-off disappears; the others stay.
- `Top` applies after grouping, not before.
- Ties stay in the inner selector's order.
- The tags are set only when `Activity.Current` is the `mnemosyne.recall` activity, and never carry content.
- A second `AddMnemosyneVariantSelection` call does not wrap twice.

- Create: `src/Mnemosyne.NET/VariantSelector.cs`, `tests/Mnemosyne.NET.Tests/Core/VariantSelectorTests.cs`
- Modify: `src/Mnemosyne.NET/PublicAPI.Unshipped.txt`

**Interfaces:**
- Produces: `public sealed class VariantSelector : IReasonletSelector { public VariantSelector(IReasonletSelector inner); public ValueTask<Result<IReadOnlyList<ReasonletMatch>, MnemosyneError>> RankAsync(ReasonletQuery query, IReadOnlyList<ReasonletCandidate> candidates, CancellationToken ct); }`

- [x] **Step 1: Write failing tests** in `VariantSelectorTests.cs`, using `ReasonletSelector` as the inner selector and the candidate builders in `Fakes.cs` (read it first; copy the style of `ReasonletSelectorTests`). Cover: one variant per lineage and the best inner score wins; `Top` applies after grouping; a lineage whose variants are all below the cut-off is dropped; empty candidates give an empty success; two interleaved lineages keep the inner order; equal scores stay in the inner order; an inner failure comes back unchanged; a cancelled token throws `OperationCanceledException`; a null inner throws `ArgumentNullException`; a query `Top` of 1 returns the best lineage only.
- [x] **Step 2: Build and run the new class**, expect failures. `dotnet build tests/Mnemosyne.NET.Tests -c Release`, then run the test exe with `-class Mnemosyne.NET.Tests.Core.VariantSelectorTests`.
- [x] **Step 3: Implement.** `RankAsync` calls `inner.RankAsync(query with { Top = Math.Max(1, candidates.Count) }, candidates, ct)`, returns the failure unchanged, walks the matches and keeps the first of each `LineageId` (a `HashSet<ReasonletId>`), stops at `query.Top`, and returns the list. Doc comments on every public member, as the other selector does. Add the type and its members to `PublicAPI.Unshipped.txt` in the format of the file.
- [x] **Step 4: Run the class again**, expect pass, then the whole unit project.
