# Phase 1.6 Selector and Ranking Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An agent asks `IReasonletMemory.RecallAsync` a question and gets back up to `Top` Reasonlets, best first, each with a score breakdown. The facade embeds the question, optionally resolves an intent, searches the store and ranks the results with the default selector.

**Architecture:**
- **Packages.** The core package `Mnemosyne.NET` gains `ReasonletSelector`, the `ReasonletMemory` facade, their options, internal recall telemetry and `AddMnemosyne()`.
- **Abstractions.** The query loses `Provenance` and gains `MinSimilarity`. Candidates carry the parent's metrics and the last-execution time.
- **Store.** The PostgreSQL store fills those new candidate fields.

**Tech Stack:**
- .NET 10.
- Microsoft.Extensions.AI.Abstractions, for `IEmbeddingGenerator<string, Embedding<float>>`. This dependency is new to the core package.
- Microsoft.Extensions.DependencyInjection.Abstractions.
- `System.Diagnostics.DiagnosticSource`, which is in-box.
- xunit v3.

**Spec:** `docs/superpowers/specs/2026-10-23-phase-1.6-selector-ranking-design.md`

## Global Constraints

- **House style is unchanged:**
  - members return `ValueTask<Result<T, MnemosyneError>>`;
  - `ct` comes last and has no default;
  - cancellation throws;
  - expected failures come back as results, and bugs throw;
  - every public type and member has XML docs;
  - warnings are errors;
  - packages are AOT-compatible, so no reflection.
- **New public API, all in namespace `Mnemosyne.NET`:**
  - `ReasonletSelector`;
  - `ReasonletRankingOptions`;
  - `ReasonletMemory`;
  - `MnemosyneOptions`;
  - `ServiceCollectionExtensions.AddMnemosyne`.

  Recall telemetry is internal.
- **Ranking defaults:**
  - **Weights:** similarity 0.50, success rate 0.30, freshness 0.20. Each weight is in [0, 1], and the three must sum to 1 within 1e-9.
  - `MinSimilarity` 0.5, `PriorWeight` 5, neutral prior 0.5, `FreshnessHalfLife` 30 days.
  - **Facade:** `CandidatePool` 20, raised to `Top` when `Top` is larger. `MinIntentConfidence` 0.7.
- **Formulas:**
  - `successRate = (successes + k * prior) / (runs + k)`. `prior` is 0.5 for a root, and the parent's `(ps + k*0.5)/(pr + k)` when `ParentMetrics` is present.
  - `freshness = 0.5 ^ (max(0, now - LastExecutedAt) / halfLife)`.
  - `total = wSim*sim + wSuc*successRate + wFre*freshness`.
  - **Order:** total descending, then similarity descending, then id ascending.
  - **Filter:** drop candidates with similarity below the query's `MinSimilarity`, or below the options' value when the query has none. Then take `Top`.
- **Remember defaults:**
  - **Intent:** the capture's intent, else the extractor's answer at any confidence, else `"unspecified"`.
  - **Name:** the capture's name, else the first line of the question cut to 200 characters. Cut at a whole code point and trim whitespace.
- **Failures:**
  - An exception from the embedding generator or the extractor, other than `OperationCanceledException`, maps to `Unavailable`. The detail names the exception type and never includes its message.
- **Telemetry:**
  - The recall tags and instruments are copied verbatim from the spec's "Recall telemetry" section.
  - The source and meter names are `MnemosyneTelemetry.ActivitySourceName` and `MnemosyneTelemetry.MeterName`.
  - No signal carries question, intent, scope, subject, tag text, or any error or exception message.
- **Commits:**
  - Use conventional commits: `feat:`, `test:`, `docs:`. Never `fix:` for unshipped code.
  - End every commit with a blank line and `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
  - No nested parentheses in a commit body.
- **Coverage** stays at 100% line and branch, merged across `tests/Mnemosyne.NET.Tests` and `tests/Mnemosyne.NET.PostgreSql.Tests`. Run each with:

  ```
  dotnet test <project> -c Release -- --coverage --coverage-output-format cobertura --coverage-settings $PWD/coverage.config.xml
  ```
- **Tests that prune or search every scope** use `PgVectorFixture.CreateEmptyDatabaseAsync`. The others use `NewScope()`.

## Review Focus

1. **The brainstorm example ranks as the user expects.** A new version of a 100%-proven procedure, with zero runs of its own, ranks above the proven original. A close match that fails half its runs ranks last. Task 2 covers this in unit tests, and Task 5 covers it end to end against PostgreSQL.
2. **A recall where nothing passes the cut-off** returns an empty list with success, never an error, and counts in `mnemosyne.recall.empty`. Tasks 2 and 4.
3. **An embedding generator that throws an exception whose message contains the question** returns `Unavailable` and leaks the question nowhere: not in the error, not in any signal. Tasks 3 and 4.
4. **A Reasonlet whose parent was erased.** Its parent link is cut, and it ranks with the neutral prior. Task 1 covers the store side, Task 5 end to end.
5. **`Top` larger than `CandidatePool`** gets up to `Top` results, because the pool is raised to `Top`. Task 3.

    - `PriorWeight`, a double above 0;
    - `FreshnessHalfLife`, a positive `TimeSpan`.

    It also has `UnitResult<MnemosyneError> Validate()`. Each failure's path is the property name; a weight sum other than 1 fails with path `SimilarityWeight`.
  - `sealed class ReasonletSelector(ReasonletRankingOptions options, TimeProvider time) : IReasonletSelector`. The constructor throws `ArgumentNullException` for a null argument and `ArgumentException` when the options are invalid. It also exposes `internal static double SuccessRate(ReasonletMetrics own, ReasonletMetrics? parent, double priorWeight)` and `internal static double Freshness(TimeSpan age, TimeSpan halfLife)` for exact unit tests.

- [ ] **Step 1: Write the failing tests.** Use a `FakeTimeProvider`, or a minimal hand-written `TimeProvider` subclass, so the package needs no new dependency.
  - `SuccessRate`:
    - `(0,0,root)` = 0.5;
    - `(10,10,root)` = 15/15 = 1.0 exactly;
    - `(1,1,root)` = 3.5/6;
    - `(0,0,parent 100/100)` gives prior 102.5/105, so the result equals that;
    - `(2,0,parent 100/100)` is pulled down to `(0 + 5*102.5/105)/7`.
  - `Freshness`:
    - age 0 gives 1;
    - age equal to the half-life gives 0.5;
    - two half-lives give 0.25;
    - a negative age gives 1.
  - Ranking:
    - the cut-off drops similarity 0.49 at the default;
    - a query `MinSimilarity` of 0.3 keeps it;

    - ties order by similarity, then by id;
    - every `Score` component and `Total` matches the formula to 1e-12.
  - `TheBrainstormExampleRanksTheNewVersionFirst`. All three candidates were last executed now.

    - Candidate B: similarity 0.85, 40/40, root.
    - Candidate C: similarity 0.86, 0 runs, parent B's metrics.
    - Expected order: C, B, A.
  - Options validation:
    - a weight below 0 or above 1 fails;
    - weights that don't sum to 1 fail;
    - `PriorWeight` of 0 or below fails;
    - a non-positive half-life fails;
    - `MinSimilarity` outside [0, 1] fails;
    - the constructor throws on invalid options.

**Interfaces:**
- Consumes: `ReasonletSelector` and `ReasonletRankingOptions` from Task 2. The store, selector and extractor ports from Abstractions.
- Produces:
  - `sealed class MnemosyneOptions`. Init properties:
    - `CandidatePool`, an int from 1 to 200, default 20;
    - `MinIntentConfidence`, from 0 to 1, default 0.7;
    - `ReasonletRankingOptions Ranking`, default `new()`.

    It has `UnitResult<MnemosyneError> Validate()`. `Ranking`'s paths nest under `Ranking`.
  - `sealed class ReasonletMemory : IReasonletMemory`. The constructor takes `IReasonletStore`, `IReasonletSelector`, `IEmbeddingGenerator<string, Embedding<float>>`, `IIntentExtractor?`, `MnemosyneOptions` and `TimeProvider`, and throws `ArgumentNullException` for a null required argument.
  - `RecallAsync` follows the spec's "Recall, step by step". The search limit is `max(CandidatePool, Top)`, capped at 200. Validate every candidate before ranking.
  - `RememberAsync` follows the spec's "Remember through the facade". The other members delegate to the store after validation.
  - `static IServiceCollection AddMnemosyne(this IServiceCollection services, MnemosyneOptions? options = null)`. It takes an options object, as `AddMnemosynePostgreSql` does, because the options have init-only members. Null means defaults.
    - It validates the options and throws `ArgumentException` when they are invalid.
    - It registers `IReasonletMemory` as a singleton `ReasonletMemory`.
    - It calls `TryAddSingleton<IReasonletSelector>` for the default selector and `TryAddSingleton(TimeProvider.System)`.
    - It resolves `IIntentExtractor` with `GetService`, so the extractor is optional.

- [ ] **Step 1: Write the failing tests.** Use hand-written fakes for the store, the selector, the embedding generator and the extractor, recording their calls.
  - Intent resolution at recall:
    - the caller's intent wins, and the extractor isn't called;
    - an extractor result at 0.7 is used as the filter;
    - at 0.69 recall searches unfiltered;
    - with no extractor recall searches unfiltered.
  - Remember defaults:
    - intent is taken from the capture, else the extractor at any confidence, else `"unspecified"`;
    - name falls back to the first line;
    - a long first line is cut to 200 characters at a code point;
    - a question that starts with a newline uses the first non-empty line.
  - Search size: the limit is 20 for `Top` 3 and 50 for `Top` 50.
  - Failures:
    - the generator throws `HttpRequestException("secret question text")`: the result is `Unavailable`, the detail names the type, and no error field contains "secret";
    - the extractor throws: the result is the same;
    - cancellation propagates in both cases;
    - store errors and selector errors pass through.
  - Delegation: execution, feedback and erase reach the store with the same arguments.
  - DI:
    - `AddMnemosyne` with a store and a generator registered resolves `IReasonletMemory`;
    - a host-registered selector is kept;
    - invalid options throw;
    - a missing extractor is fine.
