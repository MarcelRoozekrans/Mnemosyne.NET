# Phase 2.2 Minos.NET Evaluator Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A new package, `Mnemosyne.NET.Minos`, ships `MinosReasonletEvaluator`. It judges a run with a single Minos Noul and becomes the default `IReasonletEvaluator`.

**Architecture:**
- **Questions.** A `[Questions(State = typeof(MinosJudgeState))]` record asks one Noul. Minos's generator builds the request and the parsing at compile time.
- **The evaluator.** It maps `ReasonletEvaluationRequest` to the typed state. It turns the Noul's probability into a `ReasonletEvaluation`, and maps every Minos failure to a `MnemosyneError`.
- **Registration.** `AddMnemosyneMinosEvaluator` registers it against the host's `IDecisionClient`, keyed or not.

**Tech Stack:**
- .NET 10.
- Minos.NET 1.3.0, or the latest stable version at least two weeks old.
- ZeroAlloc.Results 1.4.5.
- xunit v3.

**Spec:** `docs/superpowers/specs/2026-10-23-phase-2.2-minos-evaluator-design.md`

## Global Constraints

- **The Noul text:** "Does the answer resolve the question by following the procedure?"
- **The verdict:**
  - Score = `Probability`.
  - Success = `Probability >= SuccessThreshold`.
  - Evaluator = `EvaluatorName`.
- **`MinosEvaluatorOptions`:**
  - `SuccessThreshold`: in [0, 1], default 0.5.
  - `EvaluatorName`: non-blank, at most 100 code points, default `minos`.
  - `DecisionClientKey`: `object?`, default null.
  - `Validate()` uses the public `Check`.
- **The state:**
  - Fields, as JSON properties in this order: `question`, `intent`, `procedure`, `answer`.
  - `procedure` is a `JsonElement` parsed from `ReasonletGraphJson.Serialize(graph)`.
  - A source-generated `JsonSerializerContext` produces it.
  - Never include the agent's outcome or the Reasonlet's name.
- **Error mapping:**
  - InvalidQuestions and Disposed map to `MnemosyneErrorCode.Validation`. *(Superseded in the final review: only InvalidQuestions maps to `Validation`; Disposed and an out-of-range probability map to `Unavailable`. See the spec.)*
  - The other 11 `DecisionErrorKind`s map to `Unavailable`.
  - The message is fixed: "The Minos judge could not judge the run."
  - The detail is `minos: <Kind>`, and never contains Minos's message.
- **Exceptions and cancellation:** propagate both. The facade handles them.
- **Public API:** in namespace `Mnemosyne.NET.Minos`.
  - `MinosReasonletEvaluator`
  - `MinosEvaluatorOptions`
  - `ServiceCollectionExtensions.AddMnemosyneMinosEvaluator(this IServiceCollection, MinosEvaluatorOptions? options = null)`

  The questions and state types are internal if Minos's generator allows it. Otherwise they are public and marked `[EditorBrowsable(Never)]`. Say which one in the report.
- **Package:**
  - packable, AOT-compatible, with XML docs and a README;
  - depends only on Abstractions and the Minos.NET core package;
  - included in the AOT smoke roots and in pack-validate.
- **Commits:**
  - conventional, never `fix:`;
  - end with a blank line and `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`;
  - no nested parentheses in a commit body.
- **Coverage:** 100% line and branch, merged.

## Review Focus

1. **The procedure in the state.** The state the fake client receives carries the procedure as a nested JSON value equal to the canonical graph, not as an escaped string. Task 1.
2. **No Minos message text escapes.** A sentinel in Minos's error message reaches neither the `MnemosyneError` nor the facade's telemetry. Tasks 1 and 2.
3. **The threshold boundary.** At the default threshold, 0.4999 fails and 0.5 passes. Task 1.
4. **Keyed resolution.** It picks the keyed client and never the default one. Task 2.
5. **Transitive analyzers.** The ZeroAlloc analyzers that come in through Minos don't break the build under TreatWarningsAsErrors. Task 1, in the build step.
